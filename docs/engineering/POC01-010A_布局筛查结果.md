# Q4-B01 六端点树布局筛查

本轮把四腿、头、尾的设计需求连接成一棵固定树，并完成九档参数的有限网格筛查。九档都有满足所设树路径距离不等式的布局。新增 6 项测试，连同之前的测试共 28 项通过。

## 模型与结果含义

树包含 FRONT、REAR 两个内部节点及六个末端。四条腿分别连到前后节点；头连 FRONT，尾连 REAR。内部躯干树边暂定 50 mm，头边暂定 25 mm，腿尾树边分别选 12.5、25、37.5 mm。这些是本轮新提出的实验假设，独立于上一轮材料探测线，不能解释为已经测得的折后长度。

四腿纸面位置取左右、前后对称布置，各自位于原角部材料区；头尾末端固定在上、下边中点。枚举 x 和向内偏移各四档，共 16 个位置组合。对每个组合检查全部 15 组末端：纸面两点距离平方不得小于树上路径长度平方。所有比较使用有理数，无浮点容差。满足条件后，选取 x 加向内偏移最大的组合；并列时按 x、偏移依次确定。

这是有限网格上的精确筛查及目标排序，不是全局连续最优解。网格无解不能推断所有布局无解。距离不等式通过也不证明材料流、折痕单元、山谷分配、层序、连续碰撞或真实可折叠性；本轮没有生成 CP。

不同参数可以选中同一组端点位置，但树边需求不同。没有以参数 JSON 的变化声称真实 CP 敏感性通过。每档保存全部通过的距离证据和所有被拒位置的失败面向，便于后续解释材料竞争。
