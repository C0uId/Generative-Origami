# 折纸算法调整与开发优先级

依据《生成式折纸系统_算法优化与后续开发建议.docx》及本地 C3-C2 代码、162 份逐区间证书核对。文档中的完成度百分比属于评估意见，不作为工程验收结果。此次落实研发排序、参数投影原型和证据聚类；真实四足几何编译尚未完成。

## 已确认的问题

现有 generate_fold 生成单顶点放射结构，动物名影响旋转，参数未进入腿、尾材料分配。featureLabels 不能证明这些区域在完成态形成四足。原 validate_fold 只检查局部单顶点必要条件，不能作为真实四足 Base 的完整合法性验收。

C3-C2 的 162 份证书观察计数为 PASS=71、COLLISION=0、UNCERTAIN=91；这次只读取证据并聚类，没有重新运行连续运动认证，也没有提升等级。旧 C3-C 基线保持冻结。

| 后续门禁 | Sequence Planner | 对应几何的全部区间连续通过；原研究路径须满足 162/162 PASS、0 COLLISION、0 UNCERTAIN、closure 162/162 PASS |

对原建议作一项依赖修正：真实 Base 的筛选不能排在九档几何编译全部完成之后，否则没有可操作的材料区域。先同步定义 Base 与参数，再完成九档。真人复折是外部实物验收，软件测试不能代替。

## 算法实施约束

ParameterProjector 返回 requested、implemented、approximation_notes，默认拒绝越界，显式 snap 才吸附。新增原型只定义 short/medium/long 的实验坐标 0.25/0.5/0.75；这些数值不是实测身体比例，也不是认证可实现域。几何编译状态明确为 BLOCKED_PENDING_PHYSICAL_BASE_COMPILER。九档列表只能算实验输入，不能算九个成功几何。

BaseCompiler 必须绑定 Base ID、版本、CP 哈希和稳定材料 ID。body_to_leg_ratio 增大时应明确是身体预算增加、腿预算减少；如果改用 leg_budget，方向测试相反，不能混用。tail_ratio 必须绑定尾部有效材料路径长度。头、耳、鼻、颈固定。几何 hash 只覆盖坐标、边、面、折痕分配，另存拓扑 hash；同拓扑坐标变化也应检测。禁止用 metadata 或动物名变化证明敏感性。

九档验收需要：固定 seed、数值域和版本；每档 FOLD 结构与索引合法、面片无退化、边界完整覆盖同一正方形、无重复边和意外交叉；参数方向符合材料测量；逐档绑定独立运动证据。当前局部单顶点验证器不能冒充这些检查。

接触证明优先定位 separated/touching/sliding/release 的事件区间，再对模式稳定区间建立证书。事件位置必须用连续界隔离；采样只可提供搜索初值。每次 active-set 切换重算切线与局部图。对高频面片对复用证明模板，证据缓存必须绑定 geometry、motion、material patch、layer order、容差和算法版本。证明缺失保留 UNKNOWN，不能把预算耗尽解释成无碰撞。

## 本次实际新增

- parameter_projector.py：严格输入检查、显式吸附说明、九档实验组合。
- failure_signatures.py：逐文件读取连续证书，按面片对、失败叶节点原因和已记录模式聚类；排除 PASS 分支及旧 world-z 诊断，避免父子重复计数。记录区间、cell、时间域、原证据 JSON 指针及源文件 SHA256。缺失 mode/patch/witness 明示未知，完整嵌套证据仍可沿指针查看。
- contact_failure_clusters.json：C3-C2 实际聚类结果，共 20 类。按受影响的不同区间数排序，叶节点数作为第二排序指标。
- test_optimization.py：3 项自动测试通过，覆盖九档、边界/非有限值、显式吸附、父子去重与诊断排除。这不是几何敏感性或连续认证测试。

最集中的八组是 (1,4)、(1,3)、(0,4)、(0,5)、(1,5)、(0,6)、(2,4)、(5,7)，每组都影响 91 个区间。簇之间重叠，计数不可相加；修复单组未必增加整区间 PASS。评价改动须比较同几何、同运动下的各簇变化，再比较整区间门禁。此报告没有宣称修复了这些接触证明。
