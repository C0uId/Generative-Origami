# POC01-009A 正方形材料接入检查

本轮已实现完整纸面边界与材料面片检查，并修复一个独立研究候选的边界。它是 POC01-009 参数到几何主线的前置工作；尚未建立真实四足 Base。

## 结果

旧 Dog 示例在本项目“完整正方形、不剪纸、显式材料面”接入规则下失败：四条标为边界的边横跨纸角；没有 faces_vertices。缺少 faces_vertices 本身不表示违反通用 FOLD 格式，但不满足本项目材料接入契约。旧文件没有被修改。

新增 square_material_candidate 补入四角，沿纸边连接边界，并为原有相邻径向折痕建立多边形面片和稳定 ID。径向折痕坐标和分配保留。新候选的精确材料总面积为 1，通过平面材料门禁；没有附带旧精确几何 metadata 或运动证书，须重新建立运动模型。

新增 base_intake 按 JSON 中十进制坐标作有理数运算，检查有限二维坐标、重复/零长度边、未拆分顶点、交叉边、四边完整覆盖、面片方向和面积、边面关联。几何 hash 与拓扑 hash 分开，metadata 不参与。适用范围是单位正方形、简单逆时针面片、无剪切 CP；不处理任意 FOLD 多帧、折后重叠、孔洞或厚纸，不证明可折叠性。

12 项自动测试通过（新增 9 项、已有 3 项），覆盖角部裁切、边交叉、缺面、重复面、越界索引、非法数值、哈希敏感性及补全的确定性。没有重新运行连续 CCD。历史 71 PASS / 91 UNCERTAIN 不能转移给这个新候选。

## Base 筛选

已核对 Robert Lang 的 TreeMaker 官方介绍：它以 flap 树结构为输入生成基础折痕，适合表达四腿、头、尾的设计需求；但官方也明确指出山谷分配与折叠过程需要进一步处理。因此将其列为 Base 设计候选路线，尚未选定或导入具体 Q4-B01 CP，也未把软件可获取性当成某个模型的授权证明。

下一项是确定具有来源记录的六末端 flap 四足 Base，并登记头、尾、四腿及躯干的材料区域。随后将两个参数接入该 Base 的编译规则，生成九档真实 CP，验证腿/尾有效材料长度的方向性。当前补全的放射候选仅用于验证材料门禁，不能代替四足模型。

真实纸样两次独立复折仍待实物证据。Sequence Planner 仍受原定连续认证门槛约束。
