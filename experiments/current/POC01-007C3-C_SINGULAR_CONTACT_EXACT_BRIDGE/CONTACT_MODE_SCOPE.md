# 本轮接触证明的适用范围修正

本轮保留原始 `GoalMaterialContact.audit` 及全部世界 z 方向材料间隙数据，并用 `contact_gate.merge_contact_modes` 对真正的几何状态进行验收。

原型对所有“最终会重合”的材料点都要求世界 z 顺序。两张面片在空间中尚未接触、方向也未对齐时，这个顺序不是非穿透的必要条件。因此不能把该附加条件的失败当作碰撞，也不能要求它永久阻止一个已有完整连续分离证明的区间。第 70 区间提供了实际对照：原间隙审计未确定，但全部 28 对面片已由连续几何证明通过。

这项修正有明确边界：

- **FREE**：必须有覆盖整个时间段的分离证据，例如连续锥分离、曲率膨胀后的 VF/EE 和初始分离前提，或共动材料坐标系中的严格区间分离平面。精确公共中心只允许同一个材料点，没有有限半径豁免。
- **真实共享铰链**：必须有实际材料边、折角区间和相邻扇区证明；闭合接缝还必须有解析闭环身份。全折平的有限重合部分仍须有材料 patch。
- **持续面积贴合**：必须证明固定相对旋转乘积、有限材料对应、零间隙身份和层序。相同端点、最终面片名单和采样接近均不能替代。
- **诱导材料铰链**：相对乘积中只有一条可变真实折痕，其余旋转严格固定在原 goal 半转；所有原轴保持区分。整段支撑平面交集只在真实旋转轴，轴上材料点在当前角度及 goal 角度下恒定。有限 goal patch 的层序还必须由包含它的整张材料三角形上的非负仿射系数证明，严格零仅由原点和同一折痕索引给出。
- **未证明的接触/释放**：继续返回 UNCERTAIN。未知 PASS 原因、缺失材料或层序字段、时间覆盖不完整、近似重合轴，都不会获准通过。

新 gate 保存 `original_material_audit`、`scope_correction`、每对面片的证明模式和时间子区间。它不是另一套离散碰撞采样器；它只接受连续检查器产生的已知证明结构。局部 LP 仅提议分离平面，最终必须由全区间不等式通过。

新规则在 `(1,3)`、`(2,4)`、`(5,7)` 三类前向相对链上得到材料铰链证明。其余接触关系无法证明时保守保留，特别不使用不严格闭合的全 π Goal 推导补链材料身份。

`independent_goal_halfturn_audit.json` 另提供 Fraction 精确半转矩阵乘积证据：现有固定轴的全 π 目标并不严格闭合。该静态证据限于当前坐标和目标，不能推广为一般折纸不可行。原几何和 Goal 本轮均未修改。

整个计算继续采用已声明的条件 float64/reference 误差 guard，未声称形式化区间 libm 或原生 Tight-Inclusion 认证。
