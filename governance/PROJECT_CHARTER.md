# PROJECT_CHARTER

## Mission
Build a Generative Origami system that can turn supported targets into real, verifiable origami geometry and eventually into teachable folding sequences.

## Current strategic focus
The project is currently in the quadruped PoC path. The immediate priority is a real Q4 Base and a real Parameter-to-Geometry link. Validation research, Sequence Planner, player, APP and backend must not substitute for this missing generation link.

## Non-negotiable evidence rules
- Configuration differences are not proof of geometry differences.
- Finite tree-layout screening is not proof of a valid crease pattern or a physically foldable model.
- UNKNOWN / UNCERTAIN is not PASS.
- Software tests do not replace physical refolding evidence.
- Sequence Planner is gated by validated real geometry and continuous-path evidence.

## Owner decision boundary
A change request must be raised when a proposal materially changes project goal, Base strategy, architecture, key acceptance gates, major time/cost/quality tradeoffs, or introduces a materially better alternative route that would replace the approved baseline.
